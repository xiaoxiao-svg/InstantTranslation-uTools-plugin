# Hy-MT2 翻译插件安装说明

## 安装
1. uTools → 设置 → 插件 → 开发者工具（或直接装）
2. 将 `utools-hy-mt2` 文件夹（dist 内容）放入 uTools 插件目录
3. 或：uTools 开发者工具 → 打开 `dist/plugin.json` → 打包安装

## 首次使用
1. 呼出 uTools 输入"翻译"
2. 插件提示选择模型目录 → 选一个你想放模型的位置（比如 D:\models）
3. 点"下载模型"（1.08GB，有进度条）
4. 下载完成自动加载，即可翻译

## 功能（v0.3.6）
- 文字匹配：任意界面选中文字 → 呼出 uTools → 点"文本翻译"，自动回填并翻译
- 35 种语言互译（腾讯 Hy-MT2 官方语种）：主页输入卡左下角选"源语言"、输出卡左下角选"目标语言"
- 源语言默认自动检测：输入即识别（显示"自动检测（日语）"）；识别为中文时目标自动切英语，其余默认译中文
- 官方 prompt 模板 + 官方生成参数（temperature 0.7 / top_p 0.6 / top_k 20）
- 风格：日常 / 正式 / 简洁（设置页，走模型官方风格指令）
- 术语表：设置 → 自定义（每行一条：术语=译文，对全部语向生效）
- 历史记录 50 条，点条目回填原文/译文/语言方向，悬浮显示单条删除按钮；TTS 按当前语言发音
- 本地文件存储：配置与历史存在 `uTools 用户数据目录/utools-hy-mt2/storage.json`（透明可备份，可手动编辑；首次启动自动从旧版 utools.db 迁移）

## 速度与内存（v0.3.0 引擎换血，全部实测）
- 推理引擎换为 llama.cpp 官方 llama-server.exe（b10361 Vulkan 版，已内置插件，无需安装 Node.js）
- 首次启动引擎约 10 秒（含杀毒首次扫描），之后每次会话 4~5 秒
- 翻译 0.4~1.4 秒/句（Intel Arc 核显加速，无核显自动回退 CPU）
- 闲置 5 分钟自动睡眠：内存从 ~2.4GB 降到 ~63MB；再翻译自动唤醒约 3 秒
- 低频使用场景（一天几次）：每次打开到出译文约 4~12 秒，期间有状态提示

## 模型位置
你选择的目录下的 `Hy-MT2-1.8B-Q4_K_M.gguf`，可自由移动/备份
删除后重新打开插件 → 重新下载

## 三端
Win / Mac / Linux 通用（引擎为 Windows x64 构建，Mac/Linux 需替换对应平台 llama-server）

## 已知说明
- 首次启动会下载 llama 二进制缓存与模型（需网络），之后完全离线
- 意大利语/印尼语等无独特字符的语种自动检测可能识别为英语，可手动固定源语言
