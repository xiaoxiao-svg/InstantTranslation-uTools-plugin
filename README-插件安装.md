# Hy-MT2 翻译插件安装说明

## 安装
1. uTools → 设置 → 插件 → 开发者工具（或直接装）
2. 将 `utools-hy-mt2` 文件夹（dist 内容）放入 uTools 插件目录
3. 或：uTools 开发者工具 → 打开 `dist/plugin.json` → 打包安装

插件包只有约 150KB（不含模型和引擎，两者都按平台首次使用引导安装一次）。

## 首次使用（两步）
1. **安装推理引擎**（约 10~34MB，按平台自动匹配）：
   - 进入插件 → 点「下载引擎」（国内网络不通时：复制页面上的官方/镜像链接用浏览器下载 → 点「导入安装包」选该文件）
   - 引擎为 llama.cpp 官方构建，与模型一样只需装一次；删除后重新进入会重新引导
2. **配置模型**：点「选择目录」选模型存放位置 → 「下载模型」（1.08GB，有进度条）
3. 下载完成自动加载，即可翻译

## 三端支持（v0.4.0 起，引擎外置后三端可用）
| 平台 | 引擎 | 加速 |
|---|---|---|
| Windows x64 | llama-b10734-bin-win-vulkan-x64.zip | Vulkan（Arc/独显，无独显自动回退 CPU） |
| macOS Apple Silicon | macos-arm64.tar.gz | Metal |
| macOS Intel | macos-x64.tar.gz | Metal |
| Linux x64 | ubuntu-x64.tar.gz | CPU |

## 功能
- 文字匹配：任意界面选中文字 → 呼出 uTools → 点"文本翻译"，自动回填并翻译
- 清空源内容即同步清空译文；重进插件自动重置为空白
- 35 种语言互译（腾讯 Hy-MT2 官方语种）：主页输入卡左下角选"源语言"、输出卡左下角选"目标语言"
- 源语言默认自动检测：输入即识别；识别为中文时目标自动切英语，其余默认译中文
- 官方 prompt 模板 + 官方生成参数（temperature 0.7 / top_p 0.6 / top_k 20）
- 风格：日常 / 正式 / 简洁（设置页，走模型官方风格指令）
- 术语表：设置 → 自定义（每行一条：术语=译文，对全部语向生效）
- 历史记录 50 条，点条目回填原文/译文/语言方向，悬浮显示单条删除按钮；TTS 按当前语言发音
- 本地文件存储：配置与历史存在 `uTools 用户数据目录/utools-hy-mt2/storage.json`（透明可备份，可手动编辑）

## 速度与内存（全部实测）
- 推理引擎为 llama.cpp 官方 llama-server（b10734），已实测：引擎就绪约 10 秒（冷）/ 4~5 秒（温热）
- 翻译 0.4~1.4 秒/句（GPU 加速；无独显自动回退 CPU）
- 闲置 5 分钟自动睡眠：内存从 ~2.4GB 降到 ~63MB；再翻译自动唤醒约 3 秒
- 低频使用场景（一天几次）：每次打开到出译文约 4~12 秒，期间有状态提示

## 模型位置
你选择的目录下的 `Hy-MT2-1.8B-Q4_K_M.gguf`，可自由移动/备份
删除后重新打开插件 → 重新下载

## 常见问题
- **一键下载失败**：国内网络可能连不上 GitHub。用浏览器打开插件页显示的链接（官方直连或 gh-proxy/ghfast 镜像），下载完成后插「导入安装包」选择该文件，无需手动解压
- **macOS 首次启动被拦**（"无法验证开发者"）：系统设置 → 隐私与安全性 → 仍要打开
- **Linux 启动报错**：需要较新的系统库（glibc 2.35+，Ubuntu 22.04 / Debian 12 / Arch 等均可）
- 引擎存放于 `uTools 用户数据目录/utools-hy-mt2/engine`，模型与引擎均删除后重新打开插件 → 重新引导安装

## 已知说明
- 首次启动会下载引擎与模型（需网络），之后完全离线
- 意大利语/印尼语等无独特字符的语种自动检测可能识别为英语，可手动固定源语言
