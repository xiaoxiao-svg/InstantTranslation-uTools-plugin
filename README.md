# 即译

一个**完全离线**的本地翻译工具：选中文字一键翻译，支持 35 种语言互译。所有翻译都在你自己的电脑上完成，不上传任何内容。

## 这是什么

- 基于腾讯 Hy-MT2 官方开源模型的本地翻译插件，运行在 uTools 中
- 模型规格**官方全家桶任选**：1.8B（1.08GB 起，默认推荐）/ 7B / 30B-A3B，官方 GGUF 全部量化档位（Q4_K_M / Q6_K / Q8_0），同一目录可共存多个，设置里随时切换
- 支持 35 种语言互译：中 / 英 / 日 / 韩 / 法 / 德 / 西 / 俄 / 葡 / 意 / 阿 / 泰 / 越……及粤语、繁体中文
- 翻译内容不出本机：没有隐私顾虑，不会像云翻译那样把内容发到服务器
- 永久免费，一次安装，之后完全离线可用
- 三端通用：Windows / macOS / Linux

## 为什么做这个

日常翻译需求（阅读外文、查词、看资料）大多依赖在线翻译：要联网、内容要过服务器、还有被 AI 化改写或收费的风险。这个插件把翻译模型直接放进你的电脑（默认 1.8B 一次性安装约 1.1GB，也可选更强的 7B / 30B-A3B），之后**选中即译、即译即得**，断网也能用，没有任何平台和数据风险。

## 安装

1. 解压安装包，得到 `dist` 文件夹
2. uTools → 设置 → 插件 → 开发者工具 → 打开 `dist/plugin.json`（或把 dist 文件夹导入插件目录）
3. 完成。插件包本身只有约 120KB，引擎和模型在首次使用时按需安装

## 首次使用（一次性配置，约 5 分钟）

**第一步：安装推理引擎**（约 10~34MB，自动匹配你的系统）
1. 打开插件，点「下载引擎」→ **应用内直接下载**（国内加速镜像自动换源，进度实时可见，中断自动续传），下载完自动解压安装
2. 只要一步，装完即可用；「导入安装包」保留给已从浏览器下载过文件的用户（选 .zip / .tar.gz 即可，无需手动解压）
3. 应用内下载失败时，展开页面上的链接复制到浏览器下载，再点「导入安装包」选择该文件

**第二步：选择并下载模型**（1.8B 约 1.08GB，只需一次）
1. 在模型列表选一个规格：默认推荐 **1.8B · Q4_K_M**（最快、内存占用最低）；追求质量选 7B，硬件充足选 30B-A3B（MoE 架构，激活仅 3B，速度仍快）
2. 点「选择目录」选一个模型存放位置（之后可随时移动），再点「下载所选模型」→ **应用内直接下载**（国内直连 ModelScope 优先，无需梯子），进度条实时显示已下体积与速度，**中途取消或断网不丢进度，再点下载自动续传**，完成后自动启用
3. 「导入模型文件」保留给已下载过文件的用户：手动选 .gguf 导入即可

应用内下载失败时，点模型卡下方的「应用内下载失败？」展开手动链接，复制到浏览器下载，再点「导入模型文件」选择该文件即可（ModelScope 国内直连 → hf-mirror 国内镜像 → HuggingFace 官方站）。

**换模型 / 加规格**：设置 → 更换模型。同一目录可存多个规格，装好的直接秒切；切换在下次翻译时自动生效，无需重启 uTools。

引擎和模型都只需装一次；如果不小心删掉，重新打开插件会自动引导重装。

## 怎么用

- 呼出 uTools 输入 **「翻译」** 进入插件，输入内容点翻译
- **选中任何文字** → 呼出 uTools → 点 **「文本翻译」** → 自动回填并翻译（最常用的方式）
- 输入 **「翻译 你好」** → 直接翻译"你好"
- 快捷键：`Ctrl + Enter` 翻译，`Ctrl + Delete` 清空
- 语言方向：输入卡左下角选源语言（**默认自动检测**），输出卡左下角选目标语言；识别为中文时目标自动切英语
- 设置页可调：翻译风格（日常 / 正式 / 简洁）、术语表（如 `AI=人工智能`，全局生效）、模型规格（更换模型）；「自动复制结果」开关在输出卡右下角
- **行业术语包一键添加**：设置 → 术语表，点「AI / 大模型」（71 条）「编程开发」（72 条）「医学」（77 条）「金融」（70 条）「法律」（62 条）即可批量导入该领域术语（再点一次取消）。术语只在文中出现时才生效，不影响无关内容的翻译速度
- 历史记录自动保存最近 50 条，点击可回填继续编辑

## 常见问题

| 问题 | 解决 |
|---|---|
| 「下载引擎 / 下载模型」失败 | 引擎与模型均为应用内直下（镜像/直连自动换源、断点续传）。仍失败时展开页面上的「手动链接」换一条复制到浏览器，下载完点「导入」 |
| macOS 首次运行被拦（无法验证开发者） | 系统设置 → 隐私与安全性 → 仍要打开 |
| Linux 启动报错 | 需要较新的系统库（glibc 2.35+，Ubuntu 22.04 / Debian 12 / Arch 等） |
| 配置和历史存在哪 | `uTools 用户数据目录/utools-hy-mt2/` 下的 storage.json，可随时查看/备份 |
| 想换更强 / 更快的模型 | 设置 → 更换模型，列表里选规格：已装的秒切，没装的点下载；多个规格可共存一个目录 |
| 更新插件 | 直接替换 dist 文件夹重新导入即可，配置和历史不会丢 |
| 意大利语/印尼语等识别成英语 | 无独特字符的语种自动检测会落到英语，在源语言栏手动固定即可 |

## 性能参考（实测）

- 首次启动引擎约 10 秒，之后每次打开 4~5 秒；闲置 5 分钟自动休眠释放内存，再翻译自动唤醒
- 单句翻译 0.4~1.4 秒（Windows 走 GPU 加速，无独显自动回退 CPU；macOS 走 Metal）
- 复杂长句偶尔会出现不够自然的情况，这是 1.8B 小模型的正常边界
